# @bcode-official/bcode-win32-x64

Platform-specific binary for [`@bcode-official/bcode`](https://www.npmjs.com/package/@bcode-official/bcode) on win32-x64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @bcode-official/bcode
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.
